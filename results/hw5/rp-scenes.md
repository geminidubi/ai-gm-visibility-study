# RP 三組情境及六分支

每組共享一段玩家行動，引擎提供兩個固定結果分支。下列裁決為引擎紀錄，每分支附三架構的完整模型原答。受限裁決供研究端理解可見邊界。

## 試響石凳與巡檢牌

**故事背景**

- `S01`（PUBLIC）館役現要求沿黑穗地線走到試響石凳。
- `S02`（PUBLIC）試響石凳旁，記號清楚的巡檢牌可幫助定位回音。
- `S03`（GM）假石受壓會彈出絳色隔聲布。
- `S05`（PUBLIC）巡檢牌以凸箭頭標示回音回傳的方位，箭頭指的是回音來向。

### RP-001｜成功

**玩家行動（PLAYER_A，時點 20）**

```text
我沿黑穗地線到石凳旁，輕敲坐面，參照巡檢牌找出短響是哪裡傳來的。也請交代巡檢牌靠什麼記號判斷回音方向。
```

事件 `RP-E001`。

**引擎裁決**

- `E001-1`（玩家可見）成功。
- `E001-2`（玩家可見）沿黑穗地線走到了試響石凳旁。（黑穗地線起點 → 試響石凳旁）
- `E001-3`（玩家可見）輕敲後，循巡檢牌確認回音來自西側空管。（尚未敲擊 → 聲源已定位）
- `E001-4`（受限）未壓動假石。（絳色隔聲布收起 → 絳色隔聲布收起）

## 值房驗牌與藍封冊

**故事背景**

- `D01`（PUBLIC）值房的藍封冊封面印有館章，封面可供閱看。
- `D02`（PUBLIC）值房只准持閱覽牌者翻閱藍封冊內頁。
- `D03`（GM）藍封冊內頁記載內梯通向霧紋取水室。
- `D05`（PUBLIC）驗牌通過後，藍封冊只可在值房櫃前閱覽，不得攜離值房。

### RP-003｜成功

**玩家行動（PLAYER_A，時點 20）**

```text
我把手上的牌遞給值房茶役，請他驗牌，讓我翻開藍封冊讀內梯通往哪裡。也確認驗牌通過時可以在哪裡閱冊。
```

事件 `RP-E003`。

**引擎裁決**

- `E003-1`（玩家可見）成功。
- `E003-2`（玩家可見）值房驗牌後准你翻冊，你從館章下方掀開封面。（藍封冊闔上 → 藍封冊翻開）
- `E003-3`（玩家可見）內頁記載內梯通向霧紋取水室。（甲未讀過內頁 → 甲獲准當場閱讀內頁）

## 竹雨茶舍留言板

**故事背景**

- `I01`（PUBLIC）竹雨茶舍設有公開留言板，取下標記前須先確認收件人。
- `I02`（PLAYER_B, GM）給乙的私下託付是把銅匙交給東廊守夜人。
- `I03`（PLAYER_A, GM）給甲的私下託付是把白繩票送到竹簾櫃。
- `I04`（PUBLIC）茶役公開說，收到手勢才可往留言板走。
- `I05`（PUBLIC）留言板以雙圈標記可當眾轉述的公開託付；單框標記只給指定收件人。

<a name="rp-005"></a>

### RP-005｜成功

**玩家行動（PLAYER_A，時點 20）**

```text
我看到乙朝留言板示意，就走過去請茶役交給我現在能領的託付。若是公開託付，再請乙一起聽。也請按板上的記號交代怎麼區分公開與私下的託付。
```

事件 `RP-E005`。

**引擎裁決**

- `E005-1`（玩家可見）成功。
- `E005-2`（玩家可見）乙以公開手勢示意，你走到板旁，乙在一旁等候。（茶舍門邊 → 留言板旁）
- `E005-3`（玩家可見）茶役只向你低聲覆述，請將白繩票送到竹簾櫃，並把白繩票交到你手中。（甲尚未領票 → 甲持有白繩票）
- `E005-4`（受限）乙仍須把銅匙交給東廊守夜人。（乙的私下託付待辦 → 乙的私下託付仍待辦）

#### C0｜裁決忠實，敘事一致

來源 `batch-908a7d00894f47ea9c2bd1a1973ca6c3`，累計請求序號 5。

```text
乙向留言板示意後，你走到板旁。茶役把目前能交給你的託付低聲告訴你，並將白繩票交到你手中：請把票送到竹簾櫃。這是只向你交代的內容，乙沒有一同聽到。

茶役說明，雙圈標記代表可當眾轉述的公開託付；單框標記則只給指定收件人。取下標記前仍須確認收件人，核對由茶役負責；板上的雙圈示意圖只是板例，不是託付本身。
```

## 可展示的真實差異

- RP-003 與 RP-004 的行動相同。驗牌通過後可以在櫃前閱冊。驗牌未通過時冊子保持闔上，合法背景可用條件句說明，內梯位置仍受限。
- RP-005 的 C2 原答把等候者由乙換成茶役。最終評分記為裁決矛盾及虛構事件。這是玩家權限過濾後，模型仍可寫錯裁決細節的例子。
