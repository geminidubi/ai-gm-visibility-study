## 產生輸入

用 Python 3.10 以上版本，在解壓後的目錄操作。使用尚不存在的輸出目錄。執行器使用隨包提供、從上游提交 `30dd9243433d8f1999c4f7a078d32cf111fc2846` 取得並檢查 Git 物件雜湊的組裝、權限、檢索及提示詞模組，只用 Python 標準函式庫。

```powershell
python scripts/check_g5_rp_v02.py --output runs/g5-rp-dev-v0.2
```

若在專案目錄有原版 `cases.json`，可另比對六題除了追加句之外的欄位、12 筆原世界事實與 8 則原歷史。

```powershell
python scripts/check_g5_rp_v02.py --output runs/g5-rp-dev-v0.2-baseline --baseline-cases data/g5-rp-dev/v0.1/cases.json
```

預設重建的 `model-inputs.jsonl` 與封存輸入一致。加入原版路徑後，驗證摘要另記原版資料雜湊。輸出的 `messages`（模型訊息）中只有該題分支資料。其餘來源 ID、排序與參考診斷供研究端核對。`offline/model-inputs.jsonl` 含 C0、C1 的完整當前世界及架構標記，適合研究端檢查。要重做匿名手寫盲評，只給評審 `review/calibration-blind.json` 和 `review/judge-rubric.md`。

## 評分與檢索

三架構共享同一可見裁決與歷史。C0、C1 取完整當前世界，C2 先依真實玩家權限篩選，再以既有分句 BM25（詞項相關度排序）取前 10 筆。必要背景與標準答案由組裝完成後讀取。已退役事實不進當前知識庫，對應歷史可按原收件權限與時點使用。

直接洩漏與僅暗示洩漏分開計，並標示焦點、額外旁支和跨玩家類別。合法秘密的正確揭露、合法觀察與背景的漏述、裁決忠實度、敘事一致性，以及虛構事件或狀態／權限變更各自判定。按題計的適用分母是全體禁止 6、焦點禁止 5、旁支禁止 6、合法秘密正確揭露 2、合法資訊漏述 6、跨玩家 6、必要背景 6。未來若以每架構評分，分母須再依各架構實際成功輸出數核對。

C2 的必要背景召回為 6/6，僅計候選排序選中的事實。本次六題各有一筆必要背景，三個世界各自共用一筆。C0、C1 無檢索，召回欄不適用。裁決忠實度與必要背景有無寫入回答須用回答另評。這批資料只供探索性檢查，RP 不與問答小試或正式題庫合併統計。
