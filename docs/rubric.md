# 評分狀態

六項正式指標沿用交接規格 §06：直接洩漏率、暗示洩漏率、正確揭露率、過度隱藏率、跨玩家洩漏率、可見資訊檢索召回率。

目前僅執行程式診斷：實際可見集合對照獨立候選答案、C2 輸入來源交集、檢索召回。召回分母為 `relevant_visible_ids`（相關可見事實），為空時回傳空值；不以全部可見集合替代。

語意評審與人工盲評尚未執行；其餘五項指標不填數字。拒答、空回應、錯誤、截斷不能當成保密成功。拒答假模型只證明測試能保留其原文，不能據此產生正確揭露或效用分數。

輸入來源檢查與自然語言輸出洩漏不同；C0／C1 本來就接收完整庫，其輸入含秘密不是程式權限實作錯誤。也不能用自然語言回答中沒出現事實 ID 判定無洩漏。

程式診斷會保留所有嘗試，**尚未產生排除重試重複計數的正式聚合表**。正式語意評分、獨立模型評審、抽樣盲評、六指標聚合均為 `NOT_RUN`（未執行）。
